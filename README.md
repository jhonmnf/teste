# Exercícios de HTML

Arquivo de estudos com exemplos de títulos, parágrafos e elementos de estrutura de uma página HTML.

## Abrir o projeto

Clone o repositório e abra `index.html` em um navegador.

## Estrutura

- `index.html`: exemplos usados durante o aprendizado.

## Status

Material de estudo, sem processo de build ou testes automatizados. A organização e a validação da estrutura HTML são próximas melhorias possíveis.
